# CSS Grid Layout Exercise

HTML and CSS Grid exercise covering navigation, header, article, sidebar, and footer regions.

[Live deployment](https://assignment-three-teal.vercel.app)

## Overview

- Named page regions using CSS Grid
- Standalone HTML and stylesheet

## View locally

Clone the repository and open `index.html` in a browser, or serve the repository through a local static web server. No dependency installation or build step is required.

## Scope

A small CSS Grid learning exercise. The link to `index2.html` references a page that is not included.
